# Portfolio

My personal portfolio site, built with Next.js and React and deployed on Vercel.

**Live site:** https://sachintomy.vercel.app

## What's on it

- A short intro about me
- My projects: [TicketTracker](https://github.com/ideojo/TicketTracker) (Blazor/C#) and CPR Lifeline (a Python/Playwright team project)
- A link to my GitHub

I'm learning React and Next.js, and this site is my first project with them.

## Tech

- Next.js (App Router) and React, written in TypeScript
- Plain CSS with CSS Modules
- `next/image` for the project screenshot
- Follows the system's light or dark mode
- Deployed on Vercel, where every push to `main` redeploys the site

## Running it locally

```bash
git clone https://github.com/ideojo/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:3000.
